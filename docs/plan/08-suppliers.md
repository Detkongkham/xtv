# 08 — ຜູ້ສະໜອງ (Suppliers) ⭐ ລູກຄ້າເນັ້ນເປັນພິເສດ

## 0. ຄວາມໝາຍ ແລະ ເປົ້າໝາຍ
**ຜູ້ສະໜອງ** = ບໍລິສັດທີ່ສະໜອງຜະລິດຕະພັນໃຫ້ XTK ນຳມາຂາຍ (ເປັນຜູ້ຜະລິດ ຫຼື ຜູ້ສົ່ງອອກກໍໄດ້).

**ຂໍ້ຄວາມຫຼັກທີ່ເວັບຕ້ອງສື່:** "XTK ຂາຍຜະລິດຕະພັນຈາກຜູ້ສະໜອງນີ້". ສະນັ້ນຜູ້ເຂົ້າຊົມຕ້ອງເຫັນໄດ້ 2 ທາງ:
1. **ຈາກຜູ້ສະໜອງ → ສິນຄ້າ**: ເປີດໜ້າຜູ້ສະໜອງ ແລ້ວເຫັນທັນທີວ່າ XTK ຂາຍສິນຄ້າຫຍັງແດ່ຈາກບໍລິສັດນີ້.
2. **ຈາກສິນຄ້າ → ຜູ້ສະໜອງ**: ທຸກໜ້າສິນຄ້າ ແລະ ກາດສິນຄ້າບອກໃຫ້ຊັດວ່າສິນຄ້ານີ້ມາຈາກຜູ້ສະໜອງໃດ.

ຂອບເຂດ (ປັບປຸງ 22/10/2026 ຫຼັງລູກຄ້າອະທິບາຍຄວາມໝາຍ):
- ໜ້າຜູ້ສະໜອງສະເພາະ + ເມນູຫຼັກ (ຕາມທີ່ເລືອກໄວ້).
- **ເພີ່ມ:** ສະແດງຜູ້ສະໜອງໃນໜ້າສິນຄ້າ ແລະ ກາດສິນຄ້າ. ສ່ວນນີ້ຍ້າຍຈາກ "ທາງເລືອກພາຍຫຼັງ" ເຂົ້າມາໃນຂອບເຂດ ເພາະເປັນຫົວໃຈຂອງຄວາມໝາຍຂ້າງເທິງ.

## 1. ສະຖານະຂໍ້ມູນ
ປັດຈຸບັນ **ບໍ່ມີຂໍ້ມູນຜູ້ສະໜອງເລີຍ**, ທັງໃນໂປຣເຈັກ ແລະ ໃນເວັບເກົ່າ. ກ່ອນສ້າງ UI ຕ້ອງໄດ້ຂໍ້ມູນຈາກລູກຄ້າຕາມ §7. ຫ້າມໃສ່ຊື່ ຫຼື ໂລໂກ້ທີ່ເດົາເອົາ.

### 2.1 ເມນູຫຼັກ
- ເພີ່ມ **"ຜູ້ສະໜອງ"** ເປັນເມນູລະດັບບົນ, **ຖັດຈາກ "ຜະລິດຕະພັນ"** (ລຳດັບທີ 3).
- **Mega menu** ຄືກັບເມນູຜະລິດຕະພັນ:
  - ຊ້າຍ: ຫົວຂໍ້, 1 ປະໂຫຍກ ("ຜະລິດຕະພັນທີ່ XTK ຈຳໜ່າຍ ມາຈາກຜູ້ສະໜອງທີ່ໄດ້ມາດຕະຖານ"), ຕົວເລກ "N ຜູ້ສະໜອງ · M ປະເທດ" ແລະ ລິ້ງ "ເບິ່ງຜູ້ສະໜອງທັງໝົດ".
  - ຂວາ: ໂລໂກ້ຜູ້ສະໜອງຫຼັກ (`is_featured`) ສູງສຸດ 10 ອັນ, ກຣິດ 5 × 2.
- ເມນູມືຖື: ລິ້ງ "ຜູ້ສະໜອງ" ຖັດຈາກ "ຜະລິດຕະພັນ".
- Footer (ຖັນຜະລິດຕະພັນ) ແລະ ແຜນຜັງເວັບ: ເພີ່ມລິ້ງ.

### 2.4 ໜ້າສິນຄ້າ: ບລັອກ "ສະໜອງໂດຍ"
- ຢູ່ໃນຖັນຂໍ້ມູນ **ລະຫວ່າງຄຳອະທິບາຍ ແລະ ປຸ່ມຕິດຕໍ່**, ເພື່ອໃຫ້ເຫັນກ່ອນເລື່ອນລົງ.
- ຮູບແບບ: ກ່ອງ `.supplied-by` ພື້ນ `--surface`, ໂລໂກ້ສູງ 40px, ຂໍ້ຄວາມ "ສະໜອງໂດຍ **<ຊື່>** (<ປະເທດ>)", ລິ້ງ "ເບິ່ງສິນຄ້າອື່ນຈາກ <ຊື່>" ໄປໜ້າຜູ້ສະໜອງ.
- ສິນຄ້າທີ່ມາຈາກ **ຫຼາຍຜູ້ສະໜອງ**: ສະແດງໂລໂກ້ລຽງກັນ ສູງສຸດ 4 ອັນ ("ສະໜອງໂດຍ" + ລາຍຊື່).
- ຕາຕະລາງຂໍ້ມູນຈຳເພາະ: ເພີ່ມແຖວ "ຜູ້ສະໜອງ" ເປັນລິ້ງ.
- ສິນຄ້າທີ່ຍັງບໍ່ໄດ້ລະບຸຜູ້ສະໜອງ: ບໍ່ສະແດງບລັອກນີ້ (ບໍ່ສະແດງຂໍ້ຄວາມຫວ່າງ).

### 2.5 ກາດສິນຄ້າ
- ເພີ່ມແຖວນ້ອຍ (`.small`, ສີ `--muted`) ໃຕ້ຊື່ສິນຄ້າ: "ໂດຍ <ຊື່ຜູ້ສະໜອງ>". ຖ້າມີຫຼາຍອັນ: "ໂດຍ <ຊື່ທຳອິດ> +2".
- ບໍ່ໃສ່ໂລໂກ້ໃນກາດ ເພື່ອຮັກສາຄວາມສະອາດ ແລະ ຄວາມໄວ.

## 3. ກົດການອອກແບບ
ໃຊ້ tokens ແລະ ອົງປະກອບໃນ [design.md](../../design.md) ທັງໝົດ. ອົງປະກອບໃໝ່:

| ອົງປະກອບ | CSS class | ກົດ |
|---|---|---|
| ກ່ອງໂລໂກ້ | `.logo-tile` | ພື້ນ `--white`, ຂອບ 1px `--line`, ມຸມ 8px, padding 24px. ໂລໂກ້ `object-fit: contain`, ສູງສູງສຸດ 56px (ກຣິດ) / 72px (ກາດຫຼັກ) / 120px (ໜ້າລາຍລະອຽດ). Hover: ຂອບ `--brand-100` + ເງົາອ່ອນ |
| ໂລໂກ້ສີຂາວ | `.logo-tile--dark` | ພື້ນ `--brand-900` (`logo_on_dark = 1`) |
| ກາດຫຼັກ | `.card--supplier` | ອີງ `.card`. ເທິງ: ໂລໂກ້ໃນພື້ນທີ່ສູງ 140px ພື້ນ `--surface`. ລຸ່ມ: ຮູບສິນຄ້າ 3 ອັນ 64×64 |
| ບລັອກສະໜອງໂດຍ | `.supplied-by` | ພື້ນ `--surface`, ມຸມ 8px, padding 16px 20px, flex ໂລໂກ້ + ຂໍ້ຄວາມ |
| ປ້າຍຕົວແທນ (ທາງເລືອກ) | `.badge-auth` | ສະແດງສະເພາະເມື່ອມີ `partnership`. ພື້ນ `--brand-50`, ຕົວໜັງສື `--brand-600`, ໄອຄອນ shield ສີ `--accent-green` |

**ສິ່ງທີ່ຫ້າມ:**
- ຫ້າມເຮັດໂລໂກ້ເປັນສີເທົາ. ສະແດງສີຈິງ.
- ຫ້າມໃຊ້ carousel ໂລໂກ້ທີ່ໝູນເອງ. ໃຊ້ກຣິດຄົງທີ່. ຖ້າພາຍຫຼັງຕ້ອງການແຖບເລື່ອນ, ຕ້ອງມີປຸ່ມຢຸດ, ຢຸດເມື່ອ hover/focus ແລະ ບໍ່ເລື່ອນເມື່ອ `prefers-reduced-motion`.
- ຫ້າມໃຊ້ emoji ທຸງຊາດ. ສະແດງຊື່ປະເທດເປັນຂໍ້ຄວາມ.
- ຫ້າມດັດແປງ, ຕັດ ຫຼື ປ່ຽນສີໂລໂກ້.
- ຫ້າມອ້າງວ່າເປັນ "ຕົວແທນທີ່ໄດ້ຮັບອະນຸຍາດ" ຖ້າລູກຄ້າບໍ່ໄດ້ຢືນຢັນ.

**ການເຂົ້າເຖິງ ແລະ ຄວາມໄວ:**
- `alt` ຂອງໂລໂກ້ = ຊື່ຜູ້ສະໜອງ. ລິ້ງທີ່ມີແຕ່ໂລໂກ້ຕ້ອງມີ `aria-label`.
- ໂລໂກ້ມີ `width`/`height` ແລະ `loading="lazy"` ຍົກເວັ້ນ section ທຳອິດ.
- ໂລໂກ້ແຕ່ລະອັນ ≤ 15 KB. ໜ້າລວມທັງໝົດ (ບໍ່ນັບຟອນ) ≤ 600 KB.
- ຕົວກອງເຮັດວຽກຝັ່ງ browser. ບໍ່ມີ JS ກໍເຫັນທັງໝົດ.

## 5. ຂໍ້ມູນ ແລະ ຫຼັງບ້ານ
- **ຕາຕະລາງ**: `suppliers` ແລະ `product_suppliers` (ສິນຄ້າ ↔ ຜູ້ສະໜອງ ແບບ **ຫຼາຍຕໍ່ຫຼາຍ**). ເບິ່ງ [04-database.md §4.3](04-database.md).
  - ເປັນຫຼາຍຕໍ່ຫຼາຍ ເພາະສິນຄ້າໃນເວັບຫຼາຍອັນເປັນໝວດ (ເຊັ່ນ "Rapid Tests", "Syringe & Needles") ທີ່ອາດມາຈາກຫຼາຍຜູ້ສະໜອງ.
  - ຂະແໜງຂອງຜູ້ສະໜອງ **ຄິດໄລ່ຈາກສິນຄ້າ**, ບໍ່ຕ້ອງປ້ອນແຍກ ແລະ ຈຶ່ງບໍ່ຜິດກັນ.
- **Admin** `/admin/suppliers` (🔴, [03-backend.md §2.12](03-backend.md)):
  - ລາຍການ: ໂລໂກ້, ຊື່, ປະເທດ, **ຈຳນວນສິນຄ້າ**, ສະວິດ "ຫຼັກ" (ສູງສຸດ 6), ສະແດງ/ເຊື່ອງ, ລຽງລຳດັບ (ປຸ່ມ ↑ ↓, ໃຊ້ໄດ້ທັງບໍ່ມີ JS).
  - ຟອມ:
    - ຊື່, slug, ປະເທດ (ISO), ເວັບໄຊ.
    - ຂໍ້ຄວາມ 4 ພາສາ.
    - ໂລໂກ້: ສະແດງຕົວຢ່າງທັງເທິງພື້ນຂາວ ແລະ ພື້ນເຂັ້ມ.
    - ຂໍ້ມູນທາງເລືອກ: ປະເພດການເປັນຕົວແທນ, ປີທີ່ເລີ່ມ ແລະ ໃບຢັ້ງຢືນ.
  - **ເຊື່ອມສິນຄ້າ (ສຳຄັນທີ່ສຸດ)**:
    - ໃນໜ້າຜູ້ສະໜອງ: ລາຍການສິນຄ້າທີ່ເຊື່ອມ + "ເພີ່ມສິນຄ້າ" (ຄົ້ນຫາ ແລະ ເລືອກຫຼາຍອັນ) + ລຶບອອກ.
    - ໃນຟອມສິນຄ້າ: ຊ່ອງ "ຜູ້ສະໜອງ" ເລືອກໄດ້ຫຼາຍອັນ. ອັນທຳອິດເປັນຜູ້ສະໜອງຫຼັກທີ່ສະແດງກ່ອນ.
  - Dashboard: ສະແດງ "ສິນຄ້າທີ່ຍັງບໍ່ລະບຸຜູ້ສະໜອງ: N" ພ້ອມລິ້ງ, ເພື່ອໃຫ້ພະນັກງານເຕີມຈົນຄົບ.
- **ໂລໂກ້**: admin ອັບໄດ້ສະເພາະ PNG/WebP ພື້ນໂປ່ງໃສ (ກວ້າງ ≥ 400px). SVG ອັບໂດຍນັກພັດທະນາເທົ່ານັ້ນ ຫຼັງຜ່ານການລ້າງ.
- **ຊື່ປະເທດ**: `app/lang/countries.php` (4 ພາສາ ຕາມລະຫັດ ISO) ກ່ອນ, ປະເທດອື່ນໃຊ້ຊື່ຈາກ ICU (`ext-intl`, `App\Core\Countries`). ຊື່ພາສາຈີນຂອງປະເທດໃໝ່ອາດມີຕົວອັກສອນທີ່ຟອນ subset ບໍ່ມີ: Publisher ຈະເຕືອນ.
- **ໂລໂກ້ໃນເຄື່ອງແມ່ຂ່າຍ**: ອັບແລ້ວຖືກອ່ານຄືນດ້ວຍ GD (ປະເພດຈາກ `finfo`), ຫຍໍ້ໃຫ້ກວ້າງບໍ່ເກີນ 480px ແລະ ເກັບໃນ `uploads/YYYY/MM/<random>.png|webp`.
