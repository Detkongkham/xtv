## ສະຫຼຸບການຕັດສິນໃຈ

| ຫົວຂໍ້ | ຕັດສິນໃຈ | ເຫດຜົນ |
|---|---|---|
| Hosting | cPanel ຂອງ `xtklaos.com` (easywinhost) | ມີຢູ່ແລ້ວ, ບໍ່ມີຄ່າໃຊ້ຈ່າຍເພີ່ມ |
| ພາສາຫຼັງບ້ານ | PHP 8.3 ບໍ່ໃຊ້ framework | Server ບໍ່ຮອງຮັບ Node.js/Python app. PHP ແລ່ນໄດ້ທັນທີ |
| ຖານຂໍ້ມູນ | MySQL 8.0 | ມີໃນ cPanel ແລ້ວ |
| ວິທີສະແດງໜ້າເວັບ | **Static publish**: admin ກົດເຜີຍແຜ່ ແລ້ວລະບົບສ້າງໄຟລ໌ HTML | ໄວທີ່ສຸດ ແລະ ປອດໄພທີ່ສຸດໃນ shared hosting |
| ພາສາເວັບ | ລາວ, ອັງກິດ, ໄທ, ຈີນ (`lo`, `en`, `th`, `zh`) | ຮັກສາຕາມເວັບປັດຈຸບັນ |
| ທີ່ຢູ່ລະຫວ່າງພັດທະນາ | Subdomain ແຍກ (ຕົວຢ່າງ `new.xtklaos.com`) | ບໍ່ແຕະເວັບເກົ່າທີ່ `xtklaos.com` |
| ຟອມ | ມີພຽງ **ຟອມຕິດຕໍ່** | ລູກຄ້າຕັດສິນໃຈຕັດ "ຂໍໃບສະເໜີລາຄາ" ແລະ "ສະໝັກວຽກ" ອອກແລ້ວ (22/10/2026) |
| ⭐ ຜູ້ສະໜອງ | ໜ້າຜູ້ສະໜອງ + ເມນູຫຼັກ (ຖັດຈາກຜະລິດຕະພັນ) + ບອກຜູ້ສະໜອງໃນທຸກໜ້າສິນຄ້າ ແລະ ກາດສິນຄ້າ | ລູກຄ້າເນັ້ນເປັນພິເສດ: ໃຫ້ເຫັນຊັດວ່າ XTK ຂາຍສິນຄ້າຈາກຜູ້ສະໜອງໃດ. ລໍຂໍ້ມູນຈາກລູກຄ້າ (22/10/2026) |
